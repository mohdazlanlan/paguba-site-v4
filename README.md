# PAGUBA Website v2

Static HTML/CSS/JavaScript website for Koperasi Kampung Pasir Gudang Berhad.

## Pages
- Utama
- Mengenai Kami
- Produk
- Projek & Aktiviti
- Komuniti
- Hubungi Kami

## Product assets
- Bayu Terra CompostPlus
- Bayu Terra Molek Florist
- Bayu Terra Sambal Selat

## Local preview
Open `index.html` directly in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages
Push the repository to GitHub and deploy the `main` branch from the repository root using GitHub Pages.
